# Система підтримки лікаря при оцінюванні функції нирок та анемії

Вебзастосунок допомагає лікарю оцінити лабораторні показники пацієнта:

- розраховує ШКФ за формулою **CKD-EPI 2021** (креатинін, вік, стать);
- визначає категорію ШКФ **G1–G5** (KDIGO 2024);
- визначає ступінь анемії за гемоглобіном (ВООЗ 2024);
- показує заходи **для розгляду** лікарем: гемодіаліз, ESA, переливання еритроцитів.

Система не встановлює діагноз і не призначає лікування автоматично.

## Структура

```
backend/
├── api/              # шар 1: маршрути FastAPI, схеми Pydantic
├── services/         # шар 2: сценарії та інтерфейси репозиторіїв
├── domain/           # шар 3: клінічні розрахунки без залежностей
│   └── kidney.py     # ШКФ (CKD-EPI 2021), G1–G5, граничні значення креатиніну
├── infrastructure/   # шар 4: SQLAlchemy, SQLite
└── tests/
frontend/             # клієнтська частина
database/             # схема БД і довідники
docs/                 # звіти та клінічні таблиці
```

## Граничні значення вхідних даних

| Показник | Чоловіки | Жінки | Одиниця |
| --- | --- | --- | --- |
| ШКФ | 0–100 | 0–100 | мл/хв/1,73 м² |
| Креатинін | 40–1000 | 60–1000 | мкмоль/л |
| Гемоглобін | 40–170 | 30–160 | г/л |
| Еритроцити | 1–6 | 1–5 | ×10¹²/л |

## Запуск

Потрібен Python 3.10 або новіший.

```bash
cd backend
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
pytest                         # тести
uvicorn main:app --reload      # сервер на http://127.0.0.1:8000
```

Документація API з кнопкою **Try it out**: http://127.0.0.1:8000/docs

Поки що дані зберігаються в пам'яті й зникають після перезапуску сервера;
SQLite-репозиторії додає Database Developer (гілка `database`).
